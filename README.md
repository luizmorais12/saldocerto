# SaldoCerto 💰

> **Seu dinheiro no controle.**

O **SaldoCerto** é uma aplicação web completa, moderna e comercializável de gestão financeira pessoal desenvolvida em HTML5, CSS3 e JavaScript Vanilla puro.

---

## 🚀 Tecnologias

- **HTML5 Semântico**
- **CSS3 Moderno** com Custom Properties (Design System, Dark Mode nativo, Glassmorphism, Microanimações)
- **JavaScript Vanilla (ES6+)** estruturado de forma modular e reativa com `localStorage`
- **Chart.js (v4+)** via CDN para gráficos financeiros interativos
- **Lucide Icons** via CDN para iconografia moderna e consistente
- **Google Fonts** (Família Inter)

---

## 🎯 Funcionalidades Principais

- **Landing Page Comercial (SaaS)**: Hero impactante, preview do produto, recursos, planos, FAQ e CTA.
- **Dashboard Financeiro Dinâmico**: Indicadores em tempo real (saldo disponível, receitas, despesas, investimentos), fluxo de caixa e gráfico de rosca de categorias.
- **Gerenciamento de Movimentações**:
  - Receitas e Despesas com categorização, forma de pagamento, conta/cartão e recorrência.
  - Modal dinâmico para novas transações com validações em tempo real.
- **Contas Bancárias & Carteiras**: Gerenciamento de saldo por instituição (Nubank, Itaú, Dinheiro, etc.) e transferências entre contas.
- **Cartões de Crédito**: Acompanhamento de limites, fatura aberta/fechada, datas de fechamento/vencimento e compras parceladas.
- **Metas Financeiras**: Objetivos com prazos, barras de progresso percentual e registro de aportes.
- **Módulo de Investimentos**: Carteira distribuída por classes (Tesouro Direto, CDB, FIIs, Ações, Cripto), rentabilidade e rendimento acumulado.
- **Patrimônio Líquido**: Balanço patrimonial entre Ativos e Passivos/Dívidas com gráfico evolutivo.
- **Relatórios & Exportação**: Análises com filtros por período e exportação completa para CSV.
- **Preferências & Dark Mode**: Alternância suave entre tema Claro e Escuro com persistência de estado.
- **Backup & Restauração**: Exportação e importação de dados JSON e reset seguro de fábrica.

---

## 📦 Como Executar

Por ser uma aplicação 100% frontend pura sem dependências de build ou backend:

1. Clone o repositório ou faça o download dos arquivos.
2. Abra o arquivo `index.html` em qualquer navegador web moderno (Chrome, Edge, Firefox, Safari).
3. Ou utilize extensões como *Live Server* ou `npx serve .` para emular um servidor local estático.
